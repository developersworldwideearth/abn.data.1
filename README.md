# abn.data.1

Public assets for ABN Asia, served through jsDelivr.

| Folder | Contents |
|---|---|
| `images/` | article and site images |
| `audio/` | article narration (mp3) |
| `video/` | article video (mp4) |

Base URL: `https://cdn.jsdelivr.net/gh/developersworldwideearth/abn.data.1@main/`

Example: `https://cdn.jsdelivr.net/gh/developersworldwideearth/abn.data.1@main/images/abn-logo.png`

Rules: public-safe files only, lowercase hyphenated names, jsDelivr serves up to 20 MB per
file (larger media goes to Cloudflare R2).
